\section{Appendix - Program Code}\label{sec:app-code}
This appendix gives a short excerpt of the group's source code, copied without change; the full code is in the public repositories of \cref{tab:repositories}.

\Cref{lst:envelope} builds the shared envelope in which the data server returns its results (\cref{sec:tool-exposure}).

\begin{lstlisting}[language=Python,caption={The shared answer envelope, from opentrading-mcp \parencite{group2026opentradingmcp}},label={lst:envelope}]
has_data = data not in (None, {}, [], ())
body: dict[str, Any] = {
    "data": normalize_dates(data),
    "provenance": {
        "source": source,
        "as_of": utc_now_iso(),
        "timezone": TIMEZONE,
    },
    "warnings": warnings or [],
    "availability": availability or ("available" if has_data else "empty"),
}
if body["availability"] == "unavailable":
    body.update(failure_fields(data, body["warnings"]))
if data_time is not None:
    body["provenance"]["data_time"] = data_time
\end{lstlisting}
