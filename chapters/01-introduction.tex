\subsection{Project Overview}\label{sec:project-overview}
\guide{A brief overview of the project, including the main parts that will be discussed in the document, to give readers a general view of the report’s structure and content.}
OpenTrading is a harness for financial analysis and market research on Vietnamese equities.
A harness is the program around a large language model (LLM) that decides what the model sees, what it may do, and when its answer counts as finished.
The group does not train a model; the user connects a model from a provider of their choice.

The project consists of three products.
OpenTrading is the harness: a terminal program that runs the agent loop, the tools and the checks on figures.
opentrading-mcp is a market-data server that offers its data tools through the Model Context Protocol (MCP), an open standard for connecting models to tools and data \parencite{anthropic2024introducing}.
opentrading-benchmark compares OpenTrading with two general harnesses on the same model, data and scoring.

\section{Project Background}\label{sec:background}
\guide{Introduce the context and setting of the project. This may include why the project was chosen, which problem the project aims to address, and the importance of solving this issue.}
Large language models have moved from answering questions to taking actions.
An agent plans, calls tools, reads their results and decides the next step in a loop \parencite{xi2025rise,sapkota2026agents}.
Harnesses for software engineering have shown that the program around the model shapes what an agent can achieve \parencite{yang2024sweagent,wang2025openhands}.

Finance has followed with models trained on financial text \parencite{wu2023bloomberggpt,yang2023fingpt} and with surveys of their use \parencite{li2023large}.
Financial analysis, however, rests on figures.
A price, a ratio or a growth rate is either right or wrong, and the reader must be able to trace it to a source.
Studies report that language models still invent financial figures \parencite{kang2023deficiency} and fall short of human experts in multi-step reasoning over financial reports \parencite{chen2021finqa,zhu2021tatqa}.

Vietnamese financial data follows local accounting standards that general tools do not handle well \parencite{nguyen2025finstat2sql}.
The group chose this topic because it lies where these trends meet: an agent that reads Vietnamese market data and answers only with figures it has fetched.

\section{Problem Statement}\label{sec:problem}
\guide{A specific statement of the problem that the project intends to solve: causes, impacts, and specific challenges.}
\guide{Supervisor’s template section 2, Problem Description.}
A general agent is not enough for financial analysis, for three reasons.

First, models invent figures.
With a retrieval system, a strong model answered wrongly or refused \qty{81}{\percent} of questions on public company filings \parencite{islam2023financebench}, and hallucination remains serious in financial tasks \parencite{kang2023deficiency,huang2025hallucination}.

Second, models calculate poorly when they reason in words.
Writing the computation as a program gives more reliable results \parencite{chen2023program}.

Third, data sources fail, and a general agent cannot tell a failure from a valid result.
An outage, an expired data library or a stale price returns something that looks like data; the group met each of these during the project (\cref{sec:risk}).

The impact is direct: an investor who acts on an invented price or a wrong ratio can lose money.
The challenge is therefore not a stronger model but a harness that traces every figure to a tool result, runs arithmetic as commands and reports missing data as missing.

\section{Significance of the Project}\label{sec:significance}
\guide{The importance of the project: benefits, both theoretical and practical, and its impact on the scientific community, industry, or society at large.}
In theory, the project gives a controlled comparison in which only the harness changes, while the model, the data snapshot and the scoring stay the same.
Such a comparison shows which parts of an agent's result come from the harness rather than from the model; \cref{ch:results} reports what it found, including where the harnesses tied.

In practice, the project gives Vietnamese retail investors a research assistant whose figures can be checked against their sources.
The harness is released under the Apache 2.0 licence and works with free model tiers.

\section{Project Scope \& Limitations}\label{sec:scope}
\guide{What the project will and will not cover. This section helps set expectations and prevent misunderstandings.}
The project covers a research assistant that runs in a terminal for one user on one machine.
It analyses Vietnamese equities, with selected global market and macroeconomic data.
Its tools only read data unless the user allows more.

The project does not place orders: no built-in tool can trade.
It does not manage portfolios, train models, offer a web interface or serve many users.
\TBC{state whether OpenTrading may give buy, hold or sell recommendations; version 0.5.1 allows them but the README disclaims investment advice}

The project has four limitations.
It depends on external data providers and on a data server hosted on a free plan.
Free model tiers allow few requests per day.
On Windows, shell commands are not isolated from the rest of the system.
