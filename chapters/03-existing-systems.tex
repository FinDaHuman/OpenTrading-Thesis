\chapter{Existing Systems/State of the Art}\label{ch:existing}

\section{Overview of the Field}\label{sec:field}
This project sits where three lines of work meet: agentic AI, language models for finance, and agent harnesses.
An agent senses its environment, decides and acts; with an LLM as its core, it can plan, call tools and read their results \parencite{xi2025rise,wang2024survey}.
Recent surveys separate single AI agents, which complete one bounded task, from agentic AI, where several agents share goals, memory and plans \parencite{sapkota2026agents,acharya2025agentic}, and systems of cooperating agents now form a field of their own \parencite{guo2024multiagent}.
Finance was an early domain for language models, from models trained on financial text to agents that trade \parencite{li2023large,ding2026large}.
The third line studies the harness itself, the program that gives the model its tools, context and rules \parencite{yang2024sweagent}; OpenTrading belongs to this line, applied to finance.

\section{Historical Context}\label{sec:history}
The path to today's agents took about four years.
In 2022, prompting a model to write its reasoning step by step improved arithmetic and logic tasks \parencite{wei2022chain}.
In 2023, models learned to interleave reasoning with actions \parencite{yao2023react}, to decide when to call a tool \parencite{schick2023toolformer}, to search over several lines of reasoning \parencite{yao2023tree} and to learn from their own failures \parencite{shinn2023reflexion}.
The same year brought systems of several agents that split roles or debate an answer \parencite{hong2024metagpt,wu2024autogen,du2024improving}.
From 2024, research harnesses for software tasks showed that the design of the interface between model and tools changes how well an agent performs \parencite{yang2024sweagent}, and open platforms for such agents followed \parencite{wang2025openhands}.
In November 2024, the Model Context Protocol gave tools a common way to reach any model \parencite{anthropic2024introducing}.
Finance followed a parallel path.
Benchmarks of numerical reasoning over financial reports appeared in 2021 \parencite{chen2021finqa,zhu2021tatqa}.
Models trained for finance followed in 2023 \parencite{wu2023bloomberggpt,yang2023fingpt}, together with benchmarks to compare them \parencite{xie2023pixiu,xie2024finben}.
From 2024, research moved to financial agents with tools, memory and several roles \parencite{zhang2024finagent,yu2024fincon,yang2024finrobot}.

\section{Technological Advancements}\label{sec:advances}
Three advances shape this project.
Tool calling lets a model ask the program to run a function and read its result \parencite{qin2024tool}; OpenTrading relies on it for every figure, so the model fetches data and runs arithmetic through tools instead of recalling or computing in words.
MCP defines how a program offers tools and data to a model \parencite{modelcontextprotocol2025specification}.
It let the group build the data server once and use it from any harness, which also made a fair comparison possible, but it brings new security risks, such as tool descriptions that carry hidden instructions \parencite{hou2026model}.
Finally, agent harnesses have become platforms in their own right, with loops, context management and several agents \parencite{wang2025openhands}.
Long contexts remain a weakness, because models use the middle of a long input poorly \parencite{liu2024lost}.

\section{Gaps in the Literature/Technology}\label{sec:gaps}
The review shows four gaps.
First, apart from OpenTrading, none of the systems in \cref{tab:systems} tests whether the figures in the final answer came from tool results.
Second, financial work centres on models, benchmarks and trading returns; few systems aim at answers whose every figure can be traced to a source.
Third, benchmarks of agents usually compare models, not harnesses \parencite{liu2024agentbench}, and rarely report cost \parencite{kapoor2024agents}.
Fourth, the Vietnamese market, with its local accounting standards, is little covered \parencite{nguyen2025finstat2sql}.

\section{Justification for the Project}\label{sec:justification}
OpenTrading answers each gap: the harness traces figures to tool results and sends the model back when an answer claims data it never fetched; the data server returns each result with its source and time and says when a source has failed; the benchmark compares three harnesses under the same conditions and reports cost; skills cover the Vietnamese market.
Its tools cannot place orders, which limits the risks of agents acting alone \parencite{chan2023harms}.
A prompt cannot check its own sources, so OpenTrading moves part of these rules into code.
